# BudgetBridge: Personal Expense Tracker

## Project Description
BudgetBridge is a full-stack personal expense tracker that helps users record income and expenses, organize transactions by category, and view summaries of their financial activity.

## Target Users
- Students
- Young adults
- Part-time workers
- Individuals managing a personal budget

## Core Features
- User registration and login
- Add, view, edit, and delete transactions
- Categorize transactions
- Filter by date range, type, and category
- View income, expenses, and balance summary
- View category-based spending summaries

## Technology Stack
- Front-End: HTML, CSS, JavaScript
- Back-End: Node.js
- Database: MySQL
- Version Control: GitHub
- Project Management: GitHub Projects Kanban
